Welcome to my C++ practice repository! This space is dedicated to my journey of learning and applying foundational C++ programming concepts.

##  Repository Contents

This repository contains small programs and exercises focusing on different programming logic and C++ syntax:

*   **`Age.cpp`**: Practice with variables, data types, and handling user input/output.
*   **`And-Or.cpp`**: Exercises focusing on boolean logic and logical operators (`&&`, `||`).
*   **`Sum-Substration-Multiplication.cpp`**: Working with basic arithmetic operators and mathematical calculations.
*   **`Switch (case).cpp`**: Implementing the `switch-case` control flow structure for decision-making.

## How to Run

To compile and execute any of these files locally, you will need a C++ compiler (like GCC). Open your terminal and run the following commands:

```bash
# Compile the code
g++ filename.cpp -o output_name

# Run the compiled program (Linux/macOS)
./output_name

# Run the compiled program (Windows)
output_name.exe
